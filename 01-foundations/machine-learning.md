## 1. What is Machine Learning?
Machine Learning is a subfield of Artificial Intelligence (AI) focused on building systems that learn from data, identify patterns, and make decisions with minimal human intervention. Instead of relying on hard-coded rules, ML algorithms use mathematical models to find structure in data and generalize to unseen scenarios.

## 2. Core Operational Pillars

### A. Supervised Learning
The model trains on labeled data, meaning every training input is paired with its corresponding correct output target.
* **Key Tasks**: Regression (predicting continuous numerical values) and Classification (predicting categorical labels).
* **Examples**: Linear Regression, Support Vector Machines (SVMs), Random Forests.

### B. Unsupervised Learning
The model analyzes unlabeled data to uncover hidden structures, groupings, or distributions completely on its own.
* **Key Tasks**: Clustering (grouping similar items) and Dimensionality Reduction (simplifying complex data features).
* **Examples**: K-Means Clustering, Principal Component Analysis (PCA).

### C. Reinforcement Learning (RL)
An autonomous agent learns to make sequences of decisions inside an environment by maximizing a cumulative reward signal through trial-and-error.
* **Key Tasks**: Policy optimization and value-function estimation.
* **Examples**: Q-Learning, Deep Q-Networks (DQN).

## 3. The ML Workflow Pipeline
1. **Data Collection & Ingestion**: Gathering raw inputs relevant to the target problem.
2. **Data Preprocessing**: Cleaning missing fields, normalizing scales, and engineering predictive features.
3. **Model Selection**: Choosing an algorithm suitable for the data type and problem constraints.
4. **Training & Optimization**: Feeding data into the algorithm to adjust internal weights using a loss function.
5. **Evaluation**: Testing model performance on unseen data using metrics like Accuracy, Precision, Recall, or RMSE.
6. **Deployment & Monitoring**: Serving the model in production and watching for feature drift over time.
